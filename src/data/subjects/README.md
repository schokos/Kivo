# Subject-Datenstruktur

## Pflichtstruktur
- `src/data/subjects/subjects.json` listet alle Fächer
- `src/data/subjects/<fach>/subject.json` beschreibt ein Fach
- `src/data/subjects/<fach>/courses/<kurs>/index.html` ist der eingebettete Kurs-Entry
- Optional koennen Kurse eigene Unterseiten/Assets unterhalb ihres Kursordners besitzen
